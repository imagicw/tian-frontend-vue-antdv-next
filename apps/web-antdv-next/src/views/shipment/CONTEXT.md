# 国际出运

前端对"国际出运"业务域的呈现：客户/工厂档案、运编号、装箱单、出运订单、订舱、分柜/拼柜、费用分摊。完整业务规则由后端 `gths-admin` 仓库的 `admin-module-container/CONTEXT.md` 维护，两份文档独立维护，不完全一致的地方在下文标注。

## Language

**运输订单**:
菜单标题使用的名称，对应后端"出运订单（PO 明细行）"——以一条 PO 明细为边界的待运货物记录。
_Avoid_: 与后端文档核对术语时，注意"运输订单"＝"出运订单"，非另一个概念

**客户配置**:
按客户维护的分柜时点（先分柜/后分柜）、单证通知策略、挂装柜容配置等参数的档案页面；对应后端"挂装柜容配置""单证通知策略"等词条按客户匹配的配置来源。
_Avoid_: 与"订舱变更"里提到的客户配置混淆为运行时状态——这里只是配置录入入口

**工厂管理**:
出运订单关联的工厂档案维护页面，供订单选择生产工厂。

**运编号管理**:
维护 `shippingNo` 的档案页面；运编号一经关联订单即锁定所属客户，具体唯一性与订舱关系见后端"运编号订舱唯一性"词条。

**集装箱配置**:
维护柜型（体积区间、挂装参数等）的档案页面，对应后端"挂装柜容配置"中与货型无关的柜型基础参数部分。

**装箱单管理**:
出运订单的箱装明细（箱长宽高、箱规单位、箱号范围）录入与查看页面，是后端"出运订单（PO 明细行）"CBM 自动计算的数据来源。

**订舱管理**:
订舱单的创建、发布、订舱变更、取消操作的页面，对应后端"订舱"及"订舱变更"词条。

**分柜工作台**:
菜单标题为"分柜工作台"，对应后端"分柜 / 拼柜"——将出运订单箱数/包数分配到集装箱的操作界面，覆盖箱号分配、挂装包数分配两种货型。

**智能拼柜**:
自动生成可编辑装载方案草稿的辅助功能，对应后端"装载方案"词条；前端只在此页面触发建议，不在此页面直接创建或占用订舱。

**费用分摊**:
菜单标题为"费用分摊"，对应后端"正式费用分摊"与"单证回填"——单证人员为已出运订舱单录入运输费用并按运编号分摊的页面。
_Avoid_: 与宿舍管理域的"费用分摊"（部门费用拆分）混淆——两者是不同上下文里的同名词，互不关联

**操作日志**:
订舱、订单、分柜等操作的审计日志查看页面，对应后端各词条中提到的"变更日志"。
