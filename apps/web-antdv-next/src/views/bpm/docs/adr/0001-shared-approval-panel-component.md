# 待办任务详情：抽取不依赖 Drawer 的共享审批面板组件

桌面端把待办任务工作台从卡片列表改造成飞书式主从布局（左栏任务列表 + 右栏详情面板），审批详情需要同时以「页面内嵌面板」（桌面）和「Drawer」（移动端/窄屏）两种容器呈现，但内容（普通表单/自定义业务表单、时间线、任务列表、流程图、审批操作按钮）完全相同。我们把 `approval-drawer.vue` 里的内容部分拆出一个不依赖 `useVbenDrawer` 的共享内容组件 `approval-panel.vue`，桌面右栏直接内嵌它，移动端由一个只负责 Drawer 外壳的薄封装组件承载同一个内容组件。

选择拆分而不是维护两份相似的审批详情实现（桌面简化版 + 移动端 Drawer 版），是因为后续这两个容器要长期共存（移动端不会去掉 Drawer 交互），维护两份审批逻辑意味着表单渲染、字段权限、时间线、流程图这些复杂状态需要同步改两处，容易出现两端行为漂移。拆分组件是一次不小的重构，但审批详情内容今后修改只需改一处。
