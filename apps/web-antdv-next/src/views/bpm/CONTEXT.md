# BPM 工作流

通用审批工作流引擎，被宿舍管理等多个业务域复用来驱动申请审批。本文档只覆盖"流程实例如何关联并展示具体业务数据"这条线，不包括流程建模器、任务流转等其他子域。

## Language

**流程定义**:
一个可发起审批的流程模板，定义节点、表单类型和表单渲染方式。
_Avoid_: 流程模型（指设计态的可编辑版本，流程定义是其发布后的运行态快照）

**流程实例**:
依据某个流程定义发起的一次具体审批流转，通过 `businessKey` 关联到发起它的业务对象（如某个住宿申请）。
_Avoid_: 流程、审批单

**表单类型**:
流程定义上决定审批详情页如何渲染表单的字段，取值为「普通表单」或「自定义业务表单」，二者互斥。
_Avoid_: 表单模式

**普通表单**:
一种表单类型：由表单引擎（form-create）依据流程定义的字段配置动态渲染，数据来自流程实例的表单变量。
_Avoid_: 动态表单、标准表单

**自定义业务表单**:
一种表单类型：审批详情页不使用表单引擎渲染，而是加载流程定义上配置的业务表单查看组件来展示业务方自己的详情页面。
_Avoid_: 自定义表单、业务表单（单独使用"业务表单"一词时容易与"业务表单数据"混淆，需带上"自定义"限定）

**业务表单视图注册表**:
维护「表单选项 → 只读详情组件路径」映射的清单，供流程模型的表单设计页选择，也供审批详情页解析出实际要渲染的组件。
_Avoid_: 表单适配器（仅指注册表里处理历史遗留路径格式的过渡逻辑，参见下方"遗留路径垫片"）

**表单变量**:
流程实例上由表单引擎读写的扁平键值对数据，普通表单和表单兜底展示都读取它。
_Avoid_: 表单数据（易与"业务表单数据"混淆）

**业务表单数据**:
审批详情接口单独返回的、由业务方（如宿舍管理域）提供的完整业务对象数据，专供自定义业务表单组件使用，比表单变量更完整、结构化程度更高。
_Avoid_: 表单数据、业务数据快照

**表单兜底展示**:
当普通表单没有可渲染的字段配置、或自定义业务表单组件加载/渲染失败时，用通用的键值列表展示表单变量或摘要信息的兜底视图。
_Avoid_: 表单降级

**业务键**:
流程实例上指向具体业务对象的标识（如住宿申请的订单号），是 BPM 域与各业务域之间唯一的耦合点。
_Avoid_: 业务ID、关联键

**遗留路径垫片**:
业务表单视图注册表里用于把历史遗留的 `组件路径@适配器键` 格式字符串翻译成当前组件路径的过渡逻辑；不是长期设计，待历史配置数据迁移完成后应删除。
_Avoid_: 适配器（不作为正式领域概念保留）
